# Triage Labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The issue still needs evaluation |
| `needs-info` | `needs-info` | More information or a user decision is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for AI implementation |
| `ready-for-human` | `ready-for-human` | Requires human action or implementation |
| `wontfix` | `wontfix` | Deliberately rejected or not being actioned |

When a skill mentions a triage role, use its corresponding GitHub label.
