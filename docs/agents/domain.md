# Domain Docs

Atlas uses a single-context domain model.

Before working on the application:

- Read `CONTEXT.md` when it exists.
- Read relevant decisions under `docs/adr/`.
- Follow the canonical vocabulary defined in `CONTEXT.md`.
- Surface any conflict with an existing ADR rather than silently overriding it.

`CONTEXT.md` is a glossary, not an implementation specification. It is created and updated only when domain terms are resolved.

ADRs are created only for decisions that are difficult to reverse, surprising without context and based on a genuine trade-off.
