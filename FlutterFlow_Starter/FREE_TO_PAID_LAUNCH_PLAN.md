# CONNECTA free launch path

## What works now at no cost
The packaged PWA runs locally and can be installed from the browser.
It includes the CONNECTA brand, meetings, reflections, meditations, café finder,
coping tools, support ladder, service promises and transition planning.

## FlutterFlow free build
1. Create a free FlutterFlow account.
2. Create a blank responsive project called CONNECTA.
3. Upload:
   - `icons/connecta-icon-512.png`
   - `assets/connecta-logo-lockup.png`
4. Paste `CONNECTA_FlutterFlow_Build_Prompt.txt` into FlutterFlow's AI generation workflow,
   or build the listed screens manually.
5. Use app state/local state first.
6. Publish to FlutterFlow's free web address.
7. Test with fictional data only.

## First paid upgrade
Upgrade FlutterFlow only when you need code export, APK download, a custom domain,
or app-store deployment. Keep Supabase free during early testing.

## Later public pilot
Move to a secure backend only after:
- lived-experience testing
- accessibility testing
- safeguarding design
- privacy and consent design
- a Data Protection Impact Assessment
- security testing
- organisational ownership and support
