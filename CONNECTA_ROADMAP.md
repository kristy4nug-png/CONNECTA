# Atlas Project Roadmap

## Phase 1: Polished Free Local Prototype (Current)
- Single canonical local folder (`Documents\Atlas`).
- Free, local-first HTML/CSS/JS web application.
- Complete 14 core safety, recovery, fellowship, and resettlement features.
- Centred brand master logo and PWA offline capability.
- PowerShell local launcher (`Start-Atlas.ps1`).
- Complete version 0.2.0 Recovery Fellowship Finder and Personal Meeting management.
- Complete version 0.3.0 Recovery Bridge with My First 72 Hours and a consent-controlled Recovery Passport.

## Phase 2: Free Online Demonstration
- Static site hosting deployment (e.g. GitHub Pages or Netlify free tier).
- Demonstration URL for stakeholders, peer groups, and service evaluators.
- No backend required; browser `localStorage` remains local to user device.

## Phase 3: Optional Secure Test Backend
- Dedicated secure backend schema evaluation (e.g. PostgreSQL / Supabase).
- Encrypted data sync for users opting into cross-device backup.
- Strict data privacy compliance for UK healthcare & resettlement standards.
- Evaluate authorised AA, NA and ACA meeting-data feeds; do not scrape official directories.

## Phase 4: Organisation-Supported Pilot
- NHS, probation, and rehabilitation service integration.
- Professional key-worker support portal options.
- Institutional safety dashboard compliance audit.
